# AI 포토부스 스타일 갤러리

> Status: 🟢 ready · Owner: pickypic · Created: 2026-11-11

## 1. Problem
피키픽 AI 포토부스는 행사 컨셉에 맞춘 다양한 AI 연출(직업, 시대, 화풍, 캐릭터, 브랜드 광고 등)을 만들 수 있지만, 사이트의 `/ai-photobooth` 페이지에는 견본 십여 장만 있다. 그래서 행사·브랜드 담당자는 "우리 행사에 어떤 연출이 가능한지"를 한눈에 고를 수 없고, 상담에서 매번 말로 설명하거나 이미지를 따로 보내야 한다.
경쟁사(aiphotobooth.kr)는 150종 이상의 스타일을 카테고리별 갤러리로 보여 주며 "찜 → 문의"로 연결하고 있다. 같은 수준의 선택지를 보여 주지 못하면, 기능이 같아도 고객은 선택지가 더 많아 보이는 쪽으로 간다.

## 2. Scope
**In scope**
- **갤러리 페이지 `/ai-photobooth/gallery`**: 스타일 카드 격자(샘플 이미지 + 이름 + 찜 하트), 카테고리 필터, 24개씩 "더보기", 카드 클릭 시 크게 보기(원본 사진이 있으면 원본↔결과 비교), 하단 문의 버튼. ko/en/ja.
- **진입점**: `/ai-photobooth` 페이지의 "연출 견본" 섹션 아래와 히어로 버튼에 "스타일 전체 보기" 링크. 상단 메뉴는 그대로.
- **찜**: 방문자 브라우저에 저장(로그인 없음). 찜 목록 보기, "찜한 스타일로 문의하기" → `/rental`로 이동하면 렌탈문의 폼에 "관심 AI 스타일" 항목이 자동으로 채워지고, 메일·어드민 문의 기록에 함께 저장.
- **어드민 "AI 스타일" 메뉴**: 스타일 추가·수정·숨김·삭제·순서. 항목은 이름(ko/en/ja), 카테고리, 결과 이미지, 원본 이미지(선택), 인원(1인/2인/단체), NEW 표시, 노출 여부. 저장하면 사이트 자동 재빌드.
- **Sanity 스키마 `aiStyle`** 추가. 이미지는 Sanity 이미지 CDN으로 크기·webp 변환해 내보냄.
- **카테고리**: 코드에 고정 목록(ko/en/ja 이름)으로 두고 어드민에서 고르게 함. 초안은 6장 참고.
- **샘플 이미지 일괄 생성 스크립트** `scripts/style-samples/`: 스타일 목록(JSON) + 기준 인물 사진 → Gemini API로 결과 생성 → 검수용 폴더에 저장. 검수 통과분만 어드민으로 업로드.

**Out of scope**
- 경쟁사 이미지·문구·스타일명 복제 (구조만 참고, 이미지와 이름은 자체 제작)
- 전체 방문자 기준 "인기순" 정렬 (찜 수 서버 집계)
- 방문자가 사이트에서 직접 사진을 올려 AI 체험하는 기능
- 스타일별 상세 페이지(개별 주소). 크게 보기 팝업으로 대신함
- 샘플 이미지 150종을 이번 PR에서 모두 채우는 것. 기능 출시는 초기 샘플(예: 30~40종)로 하고 이후 어드민에서 계속 추가

## 3. User scenarios
- **행사 담당자 탐색**: AI 포토부스 페이지 → "스타일 전체 보기" → "전통" 카테고리 선택 → 한복·궁중 스타일 카드 확인 → 카드 클릭해 크게 보고 원본과 비교 → 하트로 3개 찜 → "찜한 스타일로 문의하기" → 렌탈문의 폼의 "관심 AI 스타일"에 3개 이름이 채워진 채로 나머지 작성 후 제출.
- **모바일**: 375px 화면에서 2열 카드, 카테고리는 가로 스크롤 칩. 더보기로 24개씩 추가.
- **외국인**: JP 선택 → 카테고리·스타일 이름이 일본어로 바뀜(번역이 비어 있으면 한국어 이름 표시).
- **직원 등록**: 어드민 → AI 스타일 → 새 스타일 → 이름 3개 언어, 카테고리, 결과 이미지 업로드 → 저장 → 몇 분 뒤 갤러리에 노출. 숨김 처리하면 갤러리에서 사라지지만 기존 찜 목록에서는 이름만 남음.
- **스타일 0개 카테고리**: 필터 칩에 표시하지 않음.

## 5. Non-functional requirements
- **Performance:** 카드 이미지는 Sanity 이미지 CDN에서 폭 400~600px webp, lazy 로딩. 첫 화면 이미지 총량 1.5MB 이하. 페이지는 빌드 시 생성(SSG).
- **Security/Privacy:** 샘플 인물은 AI 가상 인물 또는 초상권 동의를 받은 모델만 사용. 실존 유명인·실제 브랜드 로고는 샘플에 쓰지 않음(초상권·상표). 찜 데이터는 방문자 브라우저에만 저장. 스타일 문서는 공개 데이터라 일반 ID 사용(개인정보 없음). Gemini API 키는 `.env`에만 두고 커밋하지 않음.
- **Accessibility/i18n:** 카드 이미지 alt는 스타일 이름. 하트 버튼은 `aria-pressed`, 키보드로 조작 가능. 크게 보기는 포커스가 안에 머물고 Esc로 닫힘. ko/en/jp.
- **Compatibility:** 기존 `/ai-photobooth` 디자인 체계(종이 바탕·라임 라벨)를 따름. 렌탈문의 폼의 기존 항목·검증은 그대로.
